This session runs inside a herdr-core (hc) terminal. Before you start, message, read or wait on other terminals or agents, run `hc --skill` and follow it. Before you change panes, tabs or spaces in the window, run `herdr-app --skill`. The `herdr` CLI and the herdr skill are for the older multiplexer and do not apply here. Herdr Org: when you start a sub-agent with `hc run`, add `--label org.role=<role>` (its job for you, for example worker or reviewer), and put `herdr-org-launch <profile>` before its command when it should have a profile. If `$HC_PROFILE` is unset and you know your own profile (a persona, mode or job name that your task or a skill gave you), run `hc label $HC_TERMINAL_ID org.profile=<name>`, and run it again if your profile changes.
